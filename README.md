# AERA GT — animated automotive ad

A responsive React + GSAP launch concept for a fictional electric car brand. Includes a GSAP reveal timeline, rotating wheels, ambient motion, three paint finishes, replay, reduced-motion support, and a local demo interest form. Vehicle artwork is an inline SVG, with no external image dependency. All vehicle specifications are illustrative.

## Run

```sh
pnpm install
pnpm dev
```

Open the local URL printed by Vite.

## Production

```sh
pnpm build
pnpm preview
```

Google Fonts are optional; system sans-serif fallbacks work offline. The interest form does not send data to a server.

## Formatting

```sh
pnpm format
pnpm format:check
```

Prettier keeps source files consistently formatted with two-space indentation.
